Hertford Standard is a professional portfolio and client‑management web application designed to showcase the work, capabilities, and operational maturity of a freelance software engineer.

Its purpose is twofold:

1. To attract and convert prospective clients seeking bespoke web application development, and
2. To demonstrate technical competence to existing development teams who may require outsourced engineering support.

The application targets two primary audiences:

1. Small organisations needing modern, secure, custom‑built web applications.
2. Established development teams evaluating external engineers for project‑based collaboration or overflow work.

Hertford Standard is structured as a three‑layer system:

1. Public Marketing Site. A publicly accessible front end presenting the business proposition, portfolio highlights, professional background, certifications, and a streamlined contact pathway. It includes a project outline form for initial enquiries and provides registration and login access for clients.

2. Client Dashboard. A private portal where authenticated clients can submit detailed project specifications and track progress on active work. Each project includes a timeline of updates, milestones, and notes, offering transparency and a professional, product‑like experience.

3. Admin Dashboard. A secure backend interface used by the engineer to manage clients, review submitted specifications, oversee project data, and publish timeline updates visible to clients. It mirrors the client view while providing additional administrative controls and internal‑only information.

The system is implemented using a React frontend, a PHP backend, and a MySQL database, forming a clean separation between presentation, application logic, and data storage. The architecture supports scalability, maintainability, and a division of responsibilities across the public site, client portal, and administrative tools.
